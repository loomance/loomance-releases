# Loomance

**Turn still images into short AI videos — locally, on your own NVIDIA GPU.**

Loomance is a desktop app that animates photos, illustrations and drawings using the Wan 2.2 video model running on ComfyUI. No cloud, no credits, no uploading your images anywhere — everything is generated on your PC.

🌐 [loomance.app](https://loomance.app) · 🪟 [Microsoft Store](https://apps.microsoft.com/detail/9P7F2WWM8QS3) · ⬇️ [Latest release](https://github.com/loomance/loomance-releases/releases/latest)

## Features

- **Stable Scene** — stays faithful to your image and adds natural motion
- **First → Last Frame** — animates the transition between two images you choose
- **Wild Mode** — gives the AI more freedom for creative, unexpected results
- **Automatic setup** — ComfyUI, custom nodes and models are downloaded and configured for you on first launch. No node graphs to build.
- **Private by design** — your images and prompts stay on your computer

## Requirements

| | |
|---|---|
| OS | Windows 10/11 (64-bit) or Linux (AppImage / .deb) |
| GPU | NVIDIA, 12 GB VRAM recommended |
| Disk | ~40 GB free for models |
| Internet | Required to launch the app and for the first-time model download |

## Pricing

Loomance is free to use, supported by ads. An optional ad-free subscription is available at [loomance.app](https://loomance.app).

## About this repository

This repository hosts Loomance release builds and is the place to report bugs and request features — please open an [Issue](https://github.com/loomance/loomance-releases/issues). The app source code is not public.

Loomance is built on top of open-source projects: [ComfyUI](https://github.com/comfyanonymous/ComfyUI) and the [Wan 2.2](https://github.com/Wan-Video/Wan2.2) model.
